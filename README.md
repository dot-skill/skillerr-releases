# Skillerr downloads

Skillerr is the agentic browser: a desktop browser where your AI does its research in real tabs you can watch, and keeps everything it finds in a private research graph. Free with Claude Desktop, Claude Code, Cursor, a local model or your own API key.

**Website:** https://skillerr.com

This repository only holds the installers. Get the latest from **[Releases](https://github.com/bharatdudeja13-cmd/skillerr-releases/releases/latest)**:

| Your computer | File |
|---|---|
| Mac with Apple silicon (M1–M4) | `Skillerr-<version>-arm64.dmg` |
| Mac with Intel | `Skillerr-<version>.dmg` |
| Windows (most PCs) | `Skillerr-Setup-<version>-x64.exe` |
| Windows on ARM | `Skillerr-Setup-<version>-arm64.exe` |
| Linux (x64) | `Skillerr-<version>.AppImage` |
| Linux (ARM) | `Skillerr-<version>-arm64.AppImage` |

## Opening an early build

These early builds aren't notarized by Apple or signed for Windows yet, so your system asks before opening them the first time.

- **macOS:** open the `.dmg` and drag Skillerr to Applications. Open Skillerr once; when macOS says it can't verify it, go to System Settings → Privacy & Security and click **Open Anyway**. (If an earlier download said the app was "damaged", please download again: that build is replaced.)
- **Windows:** if SmartScreen appears, click **More info** → **Run anyway**. The installer is one click and opens Skillerr when done.
- **Linux:** `chmod +x Skillerr-*.AppImage` then run it.
